## Easy Farmer's Delight 1.4.3

### Expanded modded crop support

- Added broader **Rich Farmer** compatibility for standard modded crops without requiring a hardcoded entry for every crop.
- Added **Deep Aether Squash** support, including Blue and Green Squash fruit behavior.
- Added **Eternal Starlight Nocturnal Millet**, including Forgotten Nocturnal Millet harvesting.
- Added **Hearth & Harvest** support for Cotton, Blueberry, Raspberry and compatible standard crops such as Peanut.
- Added **Regions Unexplored Salmonberry** support.
- Added **Twilight Forest** Raspberry, Blueberry, Blackberry, Maloberry, Blightberry, Duskberry, Skyberry and Stingberry bush support.
- Improved modded crop names shown by Jade and preserved the exact planting item used by configured Rich Farmers.

### Cutter improvements

- Expanded Cutter compatibility with Farmer's Delight Cutting Board recipes to all six supported tool families: **Knife, Pickaxe, Axe, Shovel, Hoe and Shears**.
- Improved Jade tool requirement reporting and retained normal Axe transformation behavior.

### Polish

- Removed redundant Rich Soil status text from Farmer Jade tooltips.
- Finalized the Grafting Support base model alignment.
